LINE自動返信 設定

基本

アカウントの名前と役割です。ここを変えれば、占い師以外のアカウント（コーチ、サロン、講師など）にも使えます。

「あなたはこの文です。」の形で AI に渡されます。

AI がどれだけ考えてから返すかです。返信はもともと時間をあけて送るので、「じっくり」でも相談者の待ち時間は変わりません（費用は上がります）。

今の設定の元になったテンプレート

別のテンプレートから作り直したいときは「状況・バックアップ」から行えます。

キャラ設定

人物像・口調・返信の型・言い回しの例など、AI がなりきるための設定です。具体的に書くほど、返信があなたらしくなります。

見出し（## など）は自由に使えます。あなたがふだん使う言い回しや決め台詞を「例:」として書いておくと、よく似た言い回しで返すようになります。

メニュー

AI が使う「術」や「得意分野」です。1つずつ、どんなときに使うか・必要な情報・手順・伝え方を書きます。オンにしたものだけが使われます。

有料サービスと誘導

相談者の気持ちが「もっと知りたい」に変わったとき、案内カードで有料サービスへ誘導します。申込みページの URL を入れると有効になります。

https:// から始まる URL を入れると、案内が有効になります。

プレビュー

案内を出す条件

オンにすると「ズバッと言い切る → 本人に『どうしたいか』を聞く → YES のときだけ案内カード」の順番になります。プログラムで強制されます。本人から希望したときは意思確認なしで案内します。

心の段階ごとの動き、フック・意思確認・案内の言い回しの例です。{商品名} {価格} は自動で置き換わります。例文をあなたの決め台詞に差し替えると効果的です。

「---」だけの行で吹き出しを分けられます。このあと、その方への AI の返信は止まり、あなたの LINE に通知が届きます。

定型文

決まった場面で送る文章です。「---」だけの行で吹き出しを分けられます。

返信タイミング

すぐには返さず、時間をあけて「既読 → 入力中 → 返信」の順で返します。命に関わる言葉があるときだけは、設定にかかわらず1分以内に返します。

この範囲でランダムに決まり、短めが多く、ときどき長めになります。混んでいるほど遅くなります。0 にするとすぐ返します。

この時間帯に届いた相談は、明けてから 0〜60 分のあいだに返します。

料金について

時間をあけて返すと、LINE の無料の返信（リプライ）の期限が切れることが多く、その場合はプッシュメッセージとして月間メッセージ数にカウントされます。相談が多い場合は、公式アカウントの料金プランを確認してください。

ルール

安全と信頼のために守らせるルールです。命に関わる相談への対応や、不安をあおらないことなどが入っています。消さずに、必要なものを書き足してください。

テスト会話

保存済みの設定で、相談者になったつもりで試せます。LINE には送られず、待ち時間もありません（AI の利用料はかかります）。
