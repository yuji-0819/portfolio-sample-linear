# 公式LINE キャラクター自動返信ツール

公式LINEに届いたメッセージに、**あなたが設定したキャラクターとして自動で返信する**ツールです。
返信文は Claude（Anthropic の AI）が作ります。キャラ・文章・メニュー・有料サービスへの誘導・返信タイミングは、すべて**ブラウザの管理画面**から設定できます。

占い師のテンプレートが入っているので、そのまま占いアカウントとして使えます。白紙テンプレートを使えば、コーチ・カウンセラー・サロン・講師など、どんなアカウントにも使えます。

```
相談者 ──LINE──▶ 公式LINE ──Webhook──▶ このサーバー ──▶ Claude（設定したキャラとして返信を作成）
   ◀────────────── 返信 ◀───────────────────┘
                                  ▲
                    あなた ── 管理画面（/admin）でキャラや文章を設定
```

## できること

- 設定したキャラクター（名前・口調・返信の型・言い回し）になりきって返信する
- 使う「術」や「得意分野」を、メニューとして自由に追加・編集する
- タロット・おみくじ等は、AI が結果を勝手に決めないよう**プログラム側で本当にランダムに引く**
- 相談者ごとに会話の流れを記憶する（生年月日などを毎回聞き直さない）
- **すぐには返さない**：数分〜数十分ランダムに間をあけ、既読 → 入力中… → 返信の順で返す
- 返信を待っている相談が多いほど遅くなり、深夜は返さず朝に返す
- 何通かに分けて届いた相談は、まとめて読んでから1回で返す
- **相談者の心の変化に合わせて、あなた本人の有料サービスへ誘導する**（ズバッと言い切る → 意思確認 → YES のときだけ案内カード）
- **購入スクショが届いたら AI を止めて、あなたに通知 → あなたが LINE で直接対応**
- 不安をあおらない・命に関わる相談には窓口を案内してすぐ返す、などの安全ルールを標準搭載

## 管理画面

`https://（あなたのサーバー）/admin` をブラウザで開き、`ADMIN_PASSWORD` に設定したパスワードでログインします（ユーザー名は何でも構いません）。スマホからも使えます。

保存すると、**再起動なしで次の返信から反映**されます。

| 画面 | 設定できること |
|---|---|
| 基本 | キャラクター名、役割（「あなたは〇〇です」の一文）、返信の丁寧さ |
| キャラ設定 | 人物像・口調・返信の型・言い回しの例など |
| メニュー | 使う術・得意分野。追加・削除・オン/オフ、使う道具（タロット・ランダム抽選）の指定 |
| 有料サービスと誘導 | サービス名・価格・申込みページの URL・説明、案内カードの見た目（プレビュー付き）、案内を出す条件、**誘導の手順（AI への指示）**、購入後のお礼文 |
| 定型文 | 友だち追加のあいさつ、リセット時の返信、エラー時の返信など |
| 返信タイミング | 返信までの時間の範囲、混雑による遅れ、深夜に返さない時間帯、購入後のお礼までの時間 |
| ルール | 安全・信頼のためのルール |
| テスト会話 | 保存した設定で、相談者になったつもりで試す（LINE には送られない）。裏側の判断（案内を出したか等）も表示 |
| 状況・バックアップ | 相談者数・返信待ちの数・有人対応中の一覧（AI に戻すボタン付き）、設定の書き出し・読み込み、テンプレートから作り直し |

### 別のアカウントでも使うには

- **1つのサーバー = 1つの公式アカウント**です。別のアカウントで使うときは、このツールをもう1つデプロイします。
- 今の設定は「状況・バックアップ」から JSON ファイルに書き出せます。別のサーバーの管理画面で読み込めば、同じキャラ・文章をそのまま使えます。
- 新しく始めるときは、テンプレート（占い師 / 白紙）を選んで作り直してから書き換えると早いです。

### 自分用のテンプレートを作るには

`templates/` の中のフォルダをコピーして中身を書き換えると、管理画面の「テンプレートから作り直す」に並びます。

```
templates/あなたのテンプレート/
├── template.json      ← 名前・役割・定型文・有料サービスの初期値
├── persona.md         ← キャラ設定
├── rules.md           ← ルール
├── welcome.txt        ← 友だち追加のあいさつ
├── offer-guide.md     ← 誘導の手順（{商品名} {価格} が置き換わる）
└── methods/*.md       ← メニュー（先頭に enabled / name / tools を書く）
```

## 有料サービスへの動線（占い師テンプレートの例）

```
 相談者の心の段階                         ボットの動き
 ──────────────────────────────────────────────────────────────────
 1. 打ち明け（不安・迷い）          → 受け止め＋本音の言い当て。売らない
 2. 手応え（「当たってる」）         → 種まき（もっと深く視られることを一度だけ匂わせる）
 3. 深掘りしたい                    → フック＋意思確認（カードはまだ出さない）
                                        ①ズバッと結論を言い切る
                                        ②根拠を1つ
                                        ③「待つだけで終わりにしたいですか？
                                            それとも本心を知って自分から動きたいですか？」
 4. 意思確認に YES（「知りたいです」） → 案内カード表示 ［BASEで申し込む］
    迷い・NO                         → 尊重して寄り添いを続ける。同じ質問は一定期間しない
 5. 本人から希望（料金は？等）       → 意思確認なしで案内カード表示
                                      │
            申込みページで購入 → 購入完了画面のスクショをトークに送信
                                      │
                    AI が画像を確認 → 有人対応モードへ（AIの返信は停止）
                                      │
             あなたの LINE に通知「受付番号 1001 / お名前 / 最近の相談」
                                      │
        あなたが LINE公式アカウントのチャット画面から直接対応
                                      │
     終わったら「#終了 1001」と送る（または管理画面のボタン）→ AI 自動返信に戻る
```

言い回しや段階ごとの動きは、管理画面の「誘導の手順」で自由に書き換えられます。

### 案内カードが出る条件（プログラムで強制）

AI が「今なら案内してよさそう」と判断したうえで、次をすべて満たしたときだけカードが出ます。数値は管理画面で変えられます。

- 申込みページの URL が設定されている
- 相談回数が一定以上（既定3回） ※本人から希望した場合は除く
- 前回の案内から一定日数（既定7日）以上たっている ※本人から希望した場合は除く
- 「死にたい」「消えたい」など命に関わる言葉が、直近の一定期間（既定14日）に出ていない ※本人から希望した場合も止めます
- 有人対応中ではない
- 「意思確認をする」がオンのときは、**先に意思確認の質問をして、相談者がはっきり YES と答えている**（本人から希望した場合は不要）

### あなた（運営者）が LINE から使うコマンド

あなた自身の LINE から、この公式アカウントのトークに送ります（`ADMIN_USER_ID` の設定が必要）。

| 送る文字 | 動き |
|---|---|
| `#一覧` | 有人対応中の相談者の一覧 |
| `#終了 1001` | 受付番号 1001 の有人対応を終え、AI の自動返信に戻す |

## 返信のタイミング

```
 14:02 相談が届く
         │  （予約に入る。すぐには返さない）
 14:15 既読がつく          ← 返信予定までのあいだのランダムなタイミング
         │
 14:31 「入力中…」→ 返信（3〜5個の吹き出し）
```

- 返信までの時間は、管理画面で決めた範囲（既定 5〜40分）でランダムに決まります。短めが多く、ときどき長めになります
- 返信待ちの相談が1件増えるごとに少しずつ遅くなります（既定 +2分）
- 深夜（既定 1〜8時）に届いた相談は、明けてから返します
- **命に関わる言葉があるときだけは、設定にかかわらず1分以内に返します**（深夜でも）
- 予約はファイルに保存されるので、サーバーを再起動しても返信は失われません

### 料金への影響（大事）

LINE は、届いたメッセージへの「リプライ（応答）」は無料ですが、リプライに使う返信用トークンには有効期限があります。
時間をあけて返すと期限が切れることが多く、その場合は「プッシュメッセージ」で送るため、**月間メッセージ数にカウントされます**。

このツールはまず無料のリプライで送ってみて、期限切れのときだけプッシュに切り替えます。相談が多い場合は、LINE公式アカウントの料金プランを確認してください。

既読をつける機能は、LINE 側の設定によっては使えないことがあります。その場合もツールは問題なく動きます。

## セットアップ手順

### 1. 必要なもの

- Node.js 20.6 以上
- LINE公式アカウント（無料で作成可）
- Anthropic の API キー（https://console.anthropic.com/ で発行。利用量に応じて課金）

### 2. 手元で動かしてみる

```bash
cd line-fortune-bot
npm install
cp .env.example .env      # .env を開いて ANTHROPIC_API_KEY と ADMIN_PASSWORD を記入
npm run chat              # ターミナル上でキャラと会話できる（LINE なしで OK）
```

LINE の設定まで済んでいれば `npm run dev` でサーバーが起動し、`http://localhost:3000/admin` で管理画面を開けます。

### 3. LINE 側の準備

1. [LINE Official Account Manager](https://manager.line.biz/) で公式アカウントを作成
2. 「設定 > Messaging API」で **Messaging API を有効化**
3. [LINE Developers コンソール](https://developers.line.biz/console/) で該当チャネルを開き、
   - 「チャネル基本設定」の **チャネルシークレット** → `LINE_CHANNEL_SECRET`
   - 「Messaging API設定」の **チャネルアクセストークン（長期）** を発行 → `LINE_CHANNEL_ACCESS_TOKEN`
   - 「チャネル基本設定」の一番下の **あなたのユーザーID** → `ADMIN_USER_ID`（申込み通知の送り先。あなた自身もこの公式アカウントを友だち追加しておく）
4. LINE Official Account Manager の「設定 > 応答設定」で
   - **応答メッセージ: オフ**（オンのままだと定型文が二重に送られます）
   - **Webhook: オン**
   - **チャット: オン**（有人対応で、あなたが直接返信するため）
   - あいさつメッセージ: オフ（管理画面の「友だち追加のあいさつ」を使うため）

### 4. サーバーを公開する（デプロイ）

Render / Railway / Google Cloud Run など、Node.js が動くサービスならどれでも使えます。

- 起動コマンド: `npm start`
- 環境変数: `.env.example` の項目を各サービスの管理画面で設定
- **`DATA_DIR` には、再起動しても消えない保存領域（Render の Disk、Railway の Volume など）を指定してください。** 設定・相談者の記録・返信予約がここに保存されます。消えると設定がテンプレートに戻り、有人対応中の方にも AI が返信を再開してしまいます
- 無料プランで「しばらくアクセスがないと停止する」サービスは、返信予約が止まるため向いていません

### 5. Webhook URL を登録

LINE Developers コンソール「Messaging API設定」で
- Webhook URL: `https://（公開したURL）/webhook`
- 「検証」ボタンで成功を確認 → **Webhook の利用: オン**

### 6. 管理画面で設定する

`https://（公開したURL）/admin` を開き、キャラ・メニュー・有料サービスを設定して保存します。「テスト会話」で確認してから運用を始めてください。

## 環境変数

キャラや文章、返信タイミングなどは管理画面で設定します。環境変数は、接続情報などサーバー側の設定だけです。

| 名前 | 既定値 | 説明 |
|---|---|---|
| `LINE_CHANNEL_SECRET` | — | 必須 |
| `LINE_CHANNEL_ACCESS_TOKEN` | — | 必須 |
| `ANTHROPIC_API_KEY` | — | 必須 |
| `ADMIN_PASSWORD` | — | 管理画面のパスワード。未設定だと管理画面は使えません |
| `ADMIN_USER_ID` | — | あなたの LINE ユーザーID（申込み通知・LINE からの管理コマンド） |
| `DATA_DIR` | `data` | 設定・相談者の記録・返信予約の保存先 |
| `TEMPLATE` | `fortune` | 初回起動時に使うテンプレート（`fortune` / `blank`） |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 使う AI モデル |
| `HISTORY_TURNS` | `20` | 1人あたり覚えておく会話の往復数 |
| `HISTORY_TTL_MINUTES` | `720` | この時間やり取りがなければ新しい相談として扱う |
| `PORT` | `3000` | サーバーのポート |

## 注意点

- スクショの判定は AI による見た目の確認です。**支払いの確認は必ず販売サイトの管理画面で行ってください。**
- あなたへの申込み通知はプッシュメッセージのため、月間メッセージ数に1通ずつカウントされます。
- 霊感・占いなどで不安をあおって結んだ契約は、消費者契約法で取り消しの対象になります。誘導の文章を書き換えるときも、怖がらせる表現や事実でない限定・人気の演出は避けてください。
- 管理画面のパスワードは長く推測されにくいものにしてください。管理画面からはキャラ設定・相談状況を見ることができます。

## ファイル構成

```
line-fortune-bot/
├── templates/          ← 初期設定のテンプレート
│   ├── fortune/        ← 占い師（月詠）
│   └── blank/          ← 白紙（どんな業種にも）
└── src/
    ├── server.js       ← LINE Webhook サーバー
    ├── settings.js     ← 設定の読み込み・保存・テンプレート
    ├── admin/          ← 管理画面（router.js と index.html）
    ├── fortune.js      ← Claude で返信を作る
    ├── prompt.js       ← 設定から AI への指示文を組み立てる
    ├── offer.js        ← 有料サービスの案内条件・誘導の指示・案内カード
    ├── handoff.js      ← 購入スクショ確認・有人対応・LINE からの管理コマンド
    ├── scheduler.js    ← 人間らしい返信タイミング（予約）
    ├── tools.js        ← タロット・ランダム抽選の道具
    ├── store.js        ← 相談者の記録・返信予約の保存
    ├── history.js      ← 会話の記憶
    ├── line.js         ← LINE 用に吹き出しを分割
    ├── chat-cli.js     ← LINE なしで試す会話ツール（npm run chat）
    └── check.js        ← 設定と AI への指示文の確認（npm run check）
```
