# 占い特化 公式LINE 自動返信ボット

公式LINEに届いたメッセージに、**占い師キャラクターとして自動で返信する**ボットです。
返信文は Claude（Anthropic の AI）が作り、口調・キャラクター・使う占術はすべてテキストファイルで指定できます。

```
相談者 ──LINE──▶ 公式LINE ──Webhook──▶ このサーバー ──▶ Claude（占い師として返信を作成）
   ◀────────────── 返信 ◀───────────────────┘
```

## できること

- 占い師キャラクター（名前・口調・鑑定の流れ）になりきって返信
- **使う占術を自分で指定**（`fortune/methods/` にファイルを置くだけ）
- タロット・おみくじ等は、AI が結果を勝手に決めないよう **プログラム側で本当にランダムに引く**
- 相談者ごとに会話の流れを記憶（生年月日などを毎回聞き直さない）
- 友だち追加時のあいさつ、「リセット」で会話のやり直し
- **すぐには返さない**：数分〜数十分ランダムに間をあけ、既読 → 入力中… → 返信の順で、人が返しているような流れにする
- 返信を待っている相談が多いほど返信が遅くなり、深夜（1時〜8時）は返さず朝に返す
- 相談者が何通かに分けて送ってきたら、まとめて読んでから1回で返す
- 返信は何個かの吹き出しに分けて送る
- 不安をあおらない・医療や法律は専門家へ・命に関わる相談は窓口を案内、などの安全ルールを標準搭載
- **相談者の心の変化に合わせて、あなた本人の「個別チャット鑑定」（BASEで販売）へ案内**
- **購入スクショが届いたら AI を止めて、あなたに通知 → あなたが LINE で直接鑑定**

## 返信のタイミング（人間らしさ・ブランディング）

```
 14:02 相談が届く
         │  （予約キューに入る。すぐには返さない）
 14:15 既読がつく          ← 返信予定までのあいだのランダムなタイミング
         │
 14:31 「入力中…」→ 返信（3〜5個の吹き出し）
```

- 返信までの時間は `REPLY_DELAY_MIN_MINUTES`〜`REPLY_DELAY_MAX_MINUTES`（既定 5〜40分）でランダム。目安は半分が17分以内、9割が35分以内です
- 返信待ちの相談が1件増えるごとに `REPLY_DELAY_PER_PENDING_MINUTES`（既定2分）ずつ遅くなります
- `QUIET_HOURS`（既定 1〜8時）に入ったら、明けてから0〜60分のあいだに返します
- 返信待ちのあいだに届いたメッセージ・スタンプは、まとめて1回の返信になります
- 予約はファイルに保存されるので、サーバーを再起動しても返信は失われません
- 長く間をあけて返すときは、トーク画面に返信予定の時刻は表示されません（既読と入力中…だけが見えます）

### 料金への影響（大事）

LINE は、届いたメッセージへの「リプライ（応答）」は無料ですが、リプライに使う返信用トークンには有効期限があります。
数分〜数十分あけて返すと期限が切れることが多く、その場合は「プッシュメッセージ」で送るため、**月間メッセージ数にカウントされます**（1回の返信で吹き出しが複数あっても1通として数えられます）。

このボットはまず無料のリプライで送ってみて、期限切れのときだけプッシュに切り替えます。
相談が多い場合は、LINE公式アカウントの有料プラン（月間メッセージ数が多いプラン）を検討してください。最新の料金と、返信用トークンの有効期限は LINE の公式サイトで確認してください。

### 既読について

既読をつける機能（`markAsRead`）は、LINE側の設定やプランによっては使えないことがあります。使えない場合もボットは問題なく動きます（既読のタイミングを調整できないだけです）。

## 個別チャット鑑定への動線

```
 相談者の心の段階                     ボットの動き
 ────────────────────────────────────────────────────────────
 1. 打ち明け（不安・迷い）      → 共感＋無料ミニ鑑定。売らない
 2. 手応え（「当たってる」）     → 信頼を深める。軽く匂わせる程度
 3. 深掘りしたい                → 案内カード表示 ［BASEで申し込む］
 4. 本人から希望（料金は？等）   → 案内カード表示
                                      │
              BASE で購入 → 購入完了画面のスクショをトークに送信
                                      │
                    AI が画像を確認 → 有人対応モードへ（AIの返信は停止）
                                      │
             あなたの LINE に通知「受付番号 1001 / お名前 / 最近の相談」
                                      │
        あなたが LINE公式アカウントのチャット画面から直接鑑定
                                      │
           鑑定が終わったら、あなたがボットに「#終了 1001」と送る → AI 自動返信に戻る
```

### 案内カードが出る条件（プログラムで強制）

AI が「今なら案内してよさそう」と判断したうえで、次をすべて満たしたときだけカードが出ます。

- 相談回数が `OFFER_MIN_TURNS`（既定3回）以上 ※本人から希望した場合は除く
- 前回の案内から `OFFER_COOLDOWN_DAYS`（既定7日）以上たっている ※本人から希望した場合は除く
- 「死にたい」「消えたい」など命に関わる言葉が、直近 `OFFER_CRISIS_BLOCK_DAYS`（既定14日）以内に出ていない ※本人から希望した場合も止めます
- 有人対応中ではない

### 設定するもの

1. `fortune/offer.md` … 鑑定の名前・価格・BASE の商品ページ URL・説明文・購入後のお礼メッセージ
   （`base_url` を入れるまで案内機能はオフです）
2. `.env` の `ADMIN_USER_ID` … あなた自身の LINE ユーザーID（通知の送り先）
   - LINE Developers コンソール「チャネル基本設定」の一番下「あなたのユーザーID」に表示されます
   - あなた自身のスマホの LINE で、この公式アカウントを友だち追加しておいてください
3. LINE Official Account Manager「設定 > 応答設定」で **チャット: オン**（Webhook と併用できます）

### あなた（運営者）が使うコマンド

あなた自身の LINE から、この公式アカウントのトークに送ります。

| 送る文字 | 動き |
|---|---|
| `#一覧` | 有人対応中の相談者の一覧 |
| `#終了 1001` | 受付番号 1001 の有人対応を終え、AI の自動返信に戻す |

### 注意

- スクショの判定は AI による見た目の確認です。**支払いの確認は必ず BASE の管理画面で行ってください。**
- あなたへの通知はプッシュメッセージのため、公式LINEの月間メッセージ数に1通ずつカウントされます。
- 霊感・占いで不安をあおって結んだ契約は、消費者契約法で取り消しの対象になります。案内文を書き換えるときも、怖がらせる表現は避けてください。

## 占い師の設定を変える

| ファイル | 内容 |
|---|---|
| `fortune/persona.md` | 占い師の名前・人物像・口調・**鑑定の型**（受け止め→言い当て→占術の根拠→見方を変える→小さな一歩→余韻）・言い回しの例 |
| `fortune/methods/*.md` | **使う占術（術）**。1つの術 = 1ファイル |
| `fortune/rules.md` | 安全・信頼のためのルール（基本は変更不要） |
| `fortune/welcome.txt` | 友だち追加されたときのあいさつ文 |

### 占術の追加方法

1. `fortune/methods/_template.md` をコピーして、`fortune/methods/好きな名前.md` を作る
2. 「どんなときに使うか」「必要な情報」「鑑定の手順」「結果の伝え方」を日本語で書く
3. カードやくじを引く術なら、先頭の `tools:` に道具を書く
   - `draw_tarot` … タロット（大アルカナ22枚 / 78枚、正逆あり）
   - `draw_random` … ファイル内の「選択肢」からランダムに選ぶ（オラクルカード、おみくじ、ルーン等）
4. サーバーを再起動

記入例が `fortune/methods/examples/` にあります（タロット・数秘術・おみくじ）。
そのまま使いたい場合は `fortune/methods/` にコピーすれば有効になります。

`npm run check` で、どの占術が読み込まれたか・AI に渡される指示文の全体を確認できます。

## セットアップ手順

### 1. 必要なもの

- Node.js 20.6 以上
- LINE公式アカウント（無料で作成可）
- Anthropic の API キー（https://console.anthropic.com/ で発行。利用量に応じて課金）

### 2. 手元で動かして口調を確認する（LINE なしで OK）

```bash
cd line-fortune-bot
npm install
cp .env.example .env      # .env を開いて ANTHROPIC_API_KEY を記入
npm run chat              # ターミナル上で占い師と会話できる
```

ここで persona.md や占術ファイルを調整しながら、返信の雰囲気を詰めるのがおすすめです。

### 3. LINE 側の準備

1. [LINE Official Account Manager](https://manager.line.biz/) で公式アカウントを作成
2. 「設定 > Messaging API」で **Messaging API を有効化**（プロバイダーを選択）
3. [LINE Developers コンソール](https://developers.line.biz/console/) で該当チャネルを開き、
   - 「チャネル基本設定」の **チャネルシークレット** → `.env` の `LINE_CHANNEL_SECRET`
   - 「Messaging API設定」の **チャネルアクセストークン（長期）** を発行 → `LINE_CHANNEL_ACCESS_TOKEN`
4. LINE Official Account Manager の「設定 > 応答設定」で
   - **応答メッセージ: オフ**（オンのままだと定型文が二重に送られます）
   - **Webhook: オン**
   - あいさつメッセージ: オフ（このボットの `welcome.txt` を使う場合）

### 4. サーバーを公開する（デプロイ）

Webhook を受けるため、インターネットから HTTPS でアクセスできる場所で動かします。
Render / Railway / Google Cloud Run など Node.js が動くサービスならどれでも可。

- 起動コマンド: `npm start`
- 環境変数: `.env.example` の項目を各サービスの管理画面で設定
- ※ 無料プランで「しばらくアクセスがないと停止する」サービスは、最初の返信が遅れることがあります

### 5. Webhook URL を登録

LINE Developers コンソール「Messaging API設定」で
- Webhook URL: `https://（公開したURL）/webhook`
- 「検証」ボタンで成功を確認 → **Webhook の利用: オン**

これで、公式LINEにメッセージを送ると占い師が返信します。

## 設定項目（環境変数）

| 名前 | 既定値 | 説明 |
|---|---|---|
| `LINE_CHANNEL_SECRET` | — | 必須 |
| `LINE_CHANNEL_ACCESS_TOKEN` | — | 必須 |
| `ANTHROPIC_API_KEY` | — | 必須 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 使う AI モデル |
| `CLAUDE_EFFORT` | `medium` | 考える深さ。`low` にすると速く安くなり、`high` にすると丁寧になるが遅くなる |
| `HISTORY_TURNS` | `20` | 1人あたり覚えておく会話の往復数 |
| `HISTORY_TTL_MINUTES` | `720` | この時間やり取りがなければ新しい相談として扱う |
| `PORT` | `3000` | サーバーのポート |
| `ADMIN_USER_ID` | — | あなたの LINE ユーザーID（申込通知・管理コマンド） |
| `OFFER_MIN_TURNS` | `3` | 何回相談を受けてから案内してよいか |
| `OFFER_COOLDOWN_DAYS` | `7` | 一度案内したら次に案内できるまでの日数 |
| `OFFER_CRISIS_BLOCK_DAYS` | `14` | 命に関わる言葉が出たら案内を止める日数 |
| `DATA_DIR` | `data` | 相談者カルテ・返信予約の保存先 |
| `REPLY_DELAY_MIN_MINUTES` | `5` | 返信までの最短（分） |
| `REPLY_DELAY_MAX_MINUTES` | `40` | 返信までの最長（分）。混雑分は別に加算 |
| `REPLY_DELAY_PER_PENDING_MINUTES` | `2` | 返信待ち1件ごとに足す分数 |
| `QUIET_HOURS` | `1-8` | 返信しない時間帯（日本時間）。空欄で無効 |
| `PURCHASE_REPLY_MIN_MINUTES` / `MAX` | `1` / `4` | 購入スクショへのお礼までの時間（分） |

## 注意点

- 相談者カルテ（会話・案内履歴・有人対応の状態）は `DATA_DIR/clients.json` に保存されます。**デプロイ先では再起動しても消えない「永続ディスク」を `DATA_DIR` に指定してください**（Render の Disk、Railway の Volume など）。消えると、有人対応中の方にも AI が返信を再開してしまいます。
- 返信は通常「リプライ」として送るため無料（月間メッセージ数にカウントされない）ですが、返信に時間がかかりすぎた場合のみプッシュメッセージで送るため、その分は公式LINEの月間メッセージ数にカウントされます。
- AI 占いであることの表示方法や、有料鑑定を行う場合の特定商取引法の表記などは、運営方針に合わせてご確認ください。

## ファイル構成

```
line-fortune-bot/
├── fortune/            ← 占い師の設定（ここを編集する）
│   ├── persona.md
│   ├── rules.md
│   ├── welcome.txt
│   ├── offer.md        ← 個別チャット鑑定（有料）の設定
│   └── methods/        ← 使う占術を置く
│       ├── _template.md
│       └── examples/   ← 記入例（タロット・数秘術・おみくじ）
└── src/
    ├── server.js       ← LINE Webhook サーバー
    ├── fortune.js      ← Claude で占い師の返信を作る
    ├── tools.js        ← タロット・ランダム抽選の道具
    ├── prompt.js       ← 設定ファイルから指示文を組み立てる
    ├── offer.js        ← 案内の条件判定・案内カード
    ├── handoff.js      ← 購入スクショ確認・有人対応・管理コマンド
    ├── scheduler.js    ← 人間らしい返信タイミング（予約キュー）
    ├── store.js        ← 相談者カルテ・返信予約の保存
    ├── history.js      ← 会話の記憶
    ├── line.js         ← LINE 用に長文を分割
    ├── chat-cli.js     ← LINE なしで試す会話ツール（npm run chat）
    └── check.js        ← 設定の読み込み確認（npm run check）
```
