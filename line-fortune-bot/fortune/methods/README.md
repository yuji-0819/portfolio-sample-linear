# 占術（使う術）の設定フォルダ

このフォルダに置いた `.md` ファイルが、占い師が使う「術」になります。

- 1つの術 = 1つのファイル（例: `tarot.md`, `numerology.md`, `shichusuimei.md`）
- ファイル名が `_` で始まるもの、`README.md`、`examples/` フォルダの中身は読み込まれません
- 新しく作るときは `_template.md` をコピーして書き換えてください
- `examples/` に記入例があります。使いたいものはこのフォルダへコピーすると有効になります
- 変更後はサーバーを再起動してください

術のファイルが1つもない場合は、占い師は特定の占術に縛られず、相談に寄り添う形で応答します。
